# Brick Sim

Brick Township, New Jersey, as a game: every real road, lane, sign, signal and building from OpenStreetMap, real
elevation from USGS 3DEP, real sun position. Ride a Segway Ninebot E2 Pro around town, go home, change clothes in the
mirror, and work an online-grocery-pickup shift at the Route 88 Walmart on your work phone.

**Play:** https://hinermandanny-dev.github.io/brick-sim/ or double-click `PLAY.cmd` (needs Node.js).

| key | what |
|---|---|
| WASD / mouse | move / look |
| F | get on / off the scooter · get in / out of the car (driver's door, left side) |
| W / S in the car | gas / brake, then reverse · Space horn |
| M → "Drive somewhere else in NJ" | Atlantic City, MATES, Sedge Island / Island Beach (`?region=ac`, `mates`, `ibsp`) |
| Space | kick off (the motor engages at 3 km/h) / jump |
| Shift or S | brake (riding) / run (walking) |
| 1 2 3 | Eco / Drive / Sport |
| Z / C | left / right blinker |
| L | headlight |
| E | use (mirror, charger, lock to a pole or rack, scan items at work) |
| G | fold and carry the scooter |
| V | first / third person |
| M | map + GPS · H | route home |
| P | work phone |
| T / Shift+T | time speed / +1 hour |
| B | set home here (public site) |

Data © OpenStreetMap contributors (ODbL). Elevation: USGS 3D Elevation Program (public domain).
